# Примитивная база данных

Консольное приложение, имитирующее работу с простой базой данных: таблицы
со столбцами типов int, str и bool, CRUD-операции и хранение данных в JSON.

## Установка

```bash
make install
```

или

```bash
uv sync
```

## Запуск

```bash
make run
```

или

```bash
uv run database
```

## Проверка стиля

```bash
make lint
```

## Управление таблицами

- `create_table <имя> <столбец:тип> ..` - создать таблицу (столбец ID
  добавляется автоматически);
- `list_tables` - показать список всех таблиц;
- `drop_table <имя>` - удалить таблицу (с подтверждением);
- `info <имя>` - информация о таблице.

## CRUD-операции

- `insert into <имя> values (<значение1>, <значение2>, ...)` - создать запись;
- `select from <имя> [where <столбец> = <значение>]` - прочитать записи;
- `update <имя> set <столбец> = <значение> where <столбец> = <значение>` -
  обновить записи;
- `delete from <имя> where <столбец> = <значение>` - удалить записи
  (с подтверждением).

Строковые значения указываются в кавычках, логические - как true или false.
